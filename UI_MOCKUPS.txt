STT App (Rust) - layout mockups
================================
Dummy data throughout. Widths assume an 80-column terminal. Colours are noted in (brackets)
because a text file can't show them.

Three options:
  A. Live panel       (recommended)  - one inline panel that updates in place
  B. Python-style                    - close copy of the current Python app
  C. Full-screen app                 - takes over the whole terminal, with tabs

"Inline" (A and B) means the app draws in the bottom part of your terminal, under whatever
was there before, and your scrollback stays usable. "Full-screen" (C) hides the scrollback
while the app is open, like htop or lazygit.


################################################################################
#  A. LIVE PANEL  (recommended)
################################################################################

Idea: one panel that never "re-prints"; it redraws in place. The mic meter is always live,
which doubles as the "the mic is hot" indicator. The panel changes colour and title when
it is actually recording. Finished dictations also print a short record into the normal
terminal scrollback above the panel, so you can scroll up to old results.

  Notes:
  - "◉ ... listening" (dim green) = the mic stream is open (hot) but NOTHING is kept.
    The meter moves when you talk so you can see it's the right mic.
  - The Whisper dot: ● green = ready, ● yellow = loading/downloading, ● red = error.
  - Keys that don't apply right now are hidden ([p] only in Prompt mode, [v] only when
    there is reasoning to view), same as the Python app.

╰──────────────────────────────────────────────────────────────────────────────╯
 [↑↓] move  [←→] change  [Enter] edit  [1-9] jump  [Esc] back

  - Choices with a few fixed values (device, quality, decoding, reasoning) change in
    place with ←→. No sub-menu needed.
  - Free text (language, folder, URL) edits in place on the line, Enter saves, Esc undoes.
  - Secrets (API key, HF token) open a masked line: ●●●●●●●●  (32 characters)
